## MVP 도구 3개 선정 추천

**선정 기준**: 높은 검색량 + 낮은 KD + 빠른 개발 시간 + 높은 재방문율

### 1순위: JSON Formatter & Validator
- **타겟 키워드**: json formatter online, json beautifier, json validator
- **합산 검색량**: 300K-800K/월
- **개발 시간**: 1-2일
- **이유**: 가장 높은 검색량, 코어 개발자 도구, 재방문율 높음

### 2순위: Base64 Encoder/Decoder
- **타겟 키워드**: base64 decode, base64 encode, base64 image decoder
- **합산 검색량**: 300K-800K/월
- **개발 시간**: 0.5-1일
- **이유**: 개발 매우 간단, 높은 검색량, 이미지 Base64도 함께 지원

### 3순위: UUID Generator
- **타겟 키워드**: uuid generator, uuid v4 generator, bulk uuid generator
- **합산 검색량**: 100K-300K/월
- **개발 시간**: 0.5일
- **이유**: 초간단 개발, 높은 검색량, 추가 기능(벌크 생성) 차별화 용이

### 대안 3순위: Timestamp/Epoch Converter
- **타겟 키워드**: unix timestamp converter, epoch converter
- **합산 검색량**: 50K-130K/월
- **개발 시간**: 0.5-1일
- **이유**: KD 매우 낮음, 개발자 필수 도구

## 실제 검증 방법 (무료 도구)

### Step 1: Google Keyword Planner (무료)
1. [Google Ads](https://ads.google.com) 계정 생성 (광고 집행 불필요)
2. 도구 → 키워드 플래너 → "새 키워드 찾기"
3. 위 키워드 입력 후 검색량 범위 확인

### Step 2: Ubersuggest (하루 3회 무료)
1. [Ubersuggest](https://neilpatel.com/ubersuggest/) 방문
2. 키워드 입력 → 검색량, SEO Difficulty, CPC 확인
3. 가장 유망한 키워드 3개씩 하루에 체크

### Step 3: Ahrefs Free Keyword Generator
1. [Ahrefs Free](https://ahrefs.com/keyword-generator) 방문
2. 키워드 입력 → KD와 검색량 확인
3. "Also rank for" 탭에서 연관 키워드 발굴

### Step 4: Google SERP 직접 분석
1. 각 키워드를 시크릿 모드에서 Google 검색
2. 1페이지 상위 10개 사이트 확인
3. 개인 블로그/소규모 사이트가 있으면 진입 가능 신호
