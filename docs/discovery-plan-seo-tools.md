## 2. Selected Idea for Validation

### #4 무료 온라인 도구 모음 사이트

**선택 근거:**
- **Google AI Overviews 내성**: 도구는 "사용"하는 것이므로 AI가 대체 불가
- **콘텐츠 패널티 무관**: 도구 자체가 콘텐츠이므로 AI 콘텐츠 패널티 리스크 없음
- **풀스택 역량 극대화**: 프론트+백엔드 개발 능력을 직접 제품에 활용
- **Evergreen**: 한 번 만들면 유지보수 최소, 장기적 수익 가능
- **자연 백링크**: 유용한 도구는 블로그/포럼에서 자연스럽게 링크됨
- **확장성**: 도구 하나하나가 독립적 SEO 페이지, 무한 확장 가능

**컨셉:**
- 개발자/디자이너를 위한 무료 온라인 도구 허브
- 각 도구가 독립적 SEO 랜딩 페이지
- 깔끔하고 빠른 UX (경쟁 사이트 대비 차별화)
- 한국어 + 영어 동시 지원

**예시 도구 카테고리:**
- **텍스트/코드**: JSON Formatter, Base64 Encode/Decode, URL Encoder, Markdown Preview
- **변환**: Color Converter (HEX↔RGB↔HSL), Unit Converter, Timestamp Converter
- **생성**: UUID Generator, Lorem Ipsum Generator, Password Generator, QR Code Generator
- **이미지**: Image Resizer, Image Compressor, SVG Optimizer, Favicon Generator
- **개발**: Regex Tester, CSS Gradient Generator, Meta Tag Generator, robots.txt Generator

## 5. Experiment Details

### EX1: 키워드 검증 (1주차, 2-3일)

**가설**: "무료 온라인 도구" 관련 키워드 중 KD가 낮고 검색량이 충분한 키워드가 다수 존재한다.

**셋업**:
1. 도구 리스트:
   - 무료: Google Keyword Planner, Ubersuggest (무료 3회/일), AnswerThePublic
   - 유료 대안: Ahrefs ($29/월), SEMrush (무료 체험)
2. 시드 키워드 50개 이상 수집:
   - "[도구명] online", "[도구명] free", "[도구명] online free"
   - 영어 + 한국어 양쪽
3. 각 키워드별 분석:
   - 월간 검색량 (Monthly Search Volume)
   - 키워드 난이도 (KD)
   - 현재 CPC (광고 단가 추정)
   - SERP Top 10 사이트의 Domain Authority

**측정 지표**: KD<30 & MSV>1000 키워드 수

**의사결정 기준**:
- ✅ 20개 이상 → 진행 (EX2 시작)
- 🟡 10-19개 → 니치 세분화 후 재검토
- ❌ 10개 미만 → 한국어 시장 우선 또는 다른 아이디어로 피벗

---

### EX2: MVP 도구 3개 개발 (2-3주차, 10-14일)

**가설**: 풀스택 역량으로 경쟁 사이트 대비 더 빠르고 깔끔한 도구를 2주 내 3개 만들 수 있다.

**셋업**:
1. 기술 스택:
   - Next.js 14+ (App Router, SSG)
   - Tailwind CSS (빠른 UI 구축)
   - Vercel (무료 호스팅, 자동 CDN)
   - 도메인 구매 (~$10-15)
2. 차별화 전략:
   - 로딩 속도: PageSpeed 90+ (경쟁 사이트 대비 우위)
   - 깔끔한 UI: 광고 최소화, 도구 중심 레이아웃
   - PWA 지원: 오프라인 사용 가능
   - 다크 모드: 개발자 선호
3. SEO 최적화:
   - 각 도구별 독립 페이지 (SSG)
   - 구조화 데이터 (SoftwareApplication schema)
   - 메타 태그, OG 태그, sitemap.xml, robots.txt
4. MVP 도구 후보 (EX1 결과에 따라 조정):
   - JSON Formatter & Validator
   - Base64 Encode/Decode
   - Color Converter (HEX↔RGB↔HSL)

**측정 지표**: 개발 완료일, PageSpeed 점수, Lighthouse 점수

**의사결정 기준**:
- ✅ 2주 내 3개 완성 & PageSpeed 90+ → 진행 (EX3, 도구 추가 개발 병행)
- 🟡 3주 소요 → 프로세스 최적화 후 계속
- ❌ 4주 이상 → 기술 스택 변경 검토 (더 간단한 프레임워크)

---

### EX3: SEO 랭킹 모니터링 (4-8주차)

**가설**: KD 30 이하 도구 키워드에서 신규 사이트도 8주 내 Top 10에 진입할 수 있다.

**셋업**:
1. Google Search Console 등록 & 사이트맵 제출
2. 무료 랭킹 트래커 (SERPWatch, Ubersuggest, 또는 수동 체크)
3. Google Analytics 4 설치
4. 주간 리포트 작성:
   - 인덱싱된 페이지 수
   - 노출 수 (Impressions)
   - 클릭 수 & CTR
   - 평균 랭킹 위치
   - 유입 키워드 분석

**측정 지표**: 타겟 키워드 랭킹 위치, 일 유니크 방문자 수

**의사결정 기준**:
- ✅ 8주 내 Top 10 진입 → 도구 확장 가속 (주 2개씩 추가)
- 🟡 Top 20 진입 → 콘텐츠 보강 (사용 가이드 추가, 내부 링크 강화)
- ❌ Top 50 밖 → 백링크 전략 추가 (게스트 포스팅, 커뮤니티 공유) 또는 키워드 재선정

**중간 체크포인트 (4주차)**:
- 인덱싱 여부 확인
- 초기 노출/클릭 데이터 리뷰
- 필요시 도구 페이지 콘텐츠 보강

---

### EX4: 광고 수익 검증 (6-10주차)

**가설**: 도구 사이트에서 UX를 해치지 않으면서 RPM $3 이상의 광고 수익을 낼 수 있다.

**셋업**:
1. AdSense 신청 조건 충족:
   - 최소 10개 이상 실질적 페이지
   - 일 100+ 방문자
   - Privacy Policy, About 페이지
2. 광고 배치 테스트:
   - A: 도구 아래 배너 (728x90)
   - B: 사이드바 (300x250)
   - C: 도구 입력/출력 사이 (인라인)
3. 측정:
   - 페이지별 RPM
   - 이탈률 변화 (광고 적용 전 vs 후)
   - 사용자 체류 시간 변화

**측정 지표**: Monthly RPM, 월 총 수익, 이탈률

**의사결정 기준**:
- ✅ RPM $3+ & 월 $50+ → 스케일업 (도구 20개로 확장, 월 $200-500 목표)
- 🟡 RPM $1-3 → 광고 배치 최적화, 프리미엄 광고 네트워크 탐색
- ❌ RPM $1 미만 → 대안 수익 모델 (제휴 마케팅, 프리미엄 도구 유료화)

## 7. Decision Framework

### Go/No-Go (8주차)

```
IF EX1 성공 (키워드 20개+)
  AND EX2 성공 (MVP 2주 내 완성)
  AND EX3 성공 (Top 10 진입 1개+)
→ PROCEED: 도구 20개로 확장, 월 $200-500 수익 목표

IF EX3 부분 성공 (Top 20)
→ ITERATE: 콘텐츠 보강 + 백링크 전략 추가, 4주 연장

IF EX1 실패 OR EX3 실패
→ PIVOT OPTIONS:
  1. 한국어 전용 시장으로 축소 (경쟁 낮음)
  2. 니치 변경: 개발자 → 디자이너/마케터 도구
  3. 아이디어 #1 (치트시트) 또는 #2 (계산기)와 하이브리드
  4. 수익 모델 변경: 광고 → 제휴 마케팅 또는 SaaS
```

### 스케일업 로드맵 (성공 시)

```
Phase 1 (Month 1-2): MVP 3개 도구 → 검증
Phase 2 (Month 3-4): 10개 도구로 확장 → 월 $100-200
Phase 3 (Month 5-8): 30개 도구 → 월 $500-1000
Phase 4 (Month 9-12): 50개+ 도구 → 월 $1000-3000
  + 프리미엄 도구 (API, 대량 처리) → 추가 수익
  + 제휴 마케팅 (호스팅, 도메인 등) → 추가 수익
```

### 기존 경쟁 사이트 분석

| 사이트 | 강점 | 약점 | 차별화 기회 |
|--------|------|------|-----------|

| smalldev.tools | 개발자 특화 | 도구 수 적음 | 더 많은 도구, 한국어 지원 |

### 핵심 차별화 포인트
1. **속도**: PageSpeed 95+ (경쟁 사이트 대부분 60-80)
2. **UX**: 광고 최소화, 다크 모드, 모바일 최적화
3. **다국어**: 한국어 + 영어 동시 지원 (한국어 시장 선점)
4. **PWA**: 오프라인 사용, 앱 설치 가능
5. **SEO**: 도구별 독립 페이지, 구조화 데이터, 사용 가이드 포함
